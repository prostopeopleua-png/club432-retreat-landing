## Мобільна продуктивність (важливі рішення)
Раніше прибрано: Lenis на тачі, рух мандали через left/top → transform, 11 blur-шарів мандали → 6 (на мобільному 1). Зорі перемальовуються після resize.

**Другий підхід, 2026-08-20** — заміряно й виправлено ще пʼять причин (усі в `@media (max-width:820px)` у globals.css):
1. **`backdrop-filter` насправді ніколи не вимикався на телефоні.** Перебивання писало `backdrop-filter:none` + `-webkit-`, і мініфікатор викидав НЕпрефіксний рядок. Тепер блюр не «вимикається на мобільному», а **вмикається лише від 821px** (`@media (min-width:821px)`). Не повертай перебивання через `none !important` — воно не працює.
2. **Три туманності** мали `blur(120–130px)` + нескінченну анімацію `breathe` (scale+opacity) → браузер перераховував повноекранне розмиття щокадру. На мобільному `.nebula { filter:none; animation:none }`.
3. **`.btn-cta`** анімувала `box-shadow` (властивість перемальовування) на 4 кнопках безперервно. Вимкнено.
4. **`.mandala-front`** — два `drop-shadow` на шарі, що постійно обертається. Фільтр вимкнено (сяйво лишається від радіальних градієнтів під мандалою).
5. Тінь карток `.frost` спрощено з 4 шарів до 2.

**Завантаження:**
- **Текст першого екрана більше не залежить від JS.** Був `opacity:0` в HTML і проявлявся лише після гідратації React + framer-motion → на повільному телефоні кілька секунд порожнього екрана. Тепер поява через CSS (`.rise-in` + `.rise-d1/2/3` у globals.css). **Не повертай framer-motion у hero.**
- Шрифти self-hosted через `next/font` (було render-blocking до fonts.googleapis.com + друге зʼєднання до fonts.gstatic.com).
- Meta Pixel — найважчий ресурс сторінки (`fbevents.js` 105 КБ + конфіг 119 КБ ≈ 2/3 ваги). Прибрати не можна, потрібен для реклами. Довгострокове рішення — Conversions API (серверні події).

⚠️ Tailwind-утиліти з `!` (напр. `!text-[13px]`) **перебивають** твої `!important` у globals.css — через шари CSS important-правила поза шаром мають НАЙнижчий пріоритет. Розміри в шапці правити класами в `page.tsx`, не в CSS.
